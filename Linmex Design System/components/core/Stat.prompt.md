Headline metric for proof strips and hero stats; large Barlow Condensed figure over a caps label.

```jsx
<Stat value="+18%" label="Plusvalía anual" />
<Stat value="12" label="Desarrollos" tone="orange" align="center" />
```

`value`, `label`, optional `sublabel`. `tone`: ink | orange | onDark (for dark sections). `align` left|center. `size` sm|md|lg.
