Surface container for grouping content; white, hairline border, soft shadow, 10px radius.

```jsx
<Card padding="lg" interactive>…</Card>
<Card accent padding="md">Con borde naranja</Card>
```

`accent` adds the left orange edge; `interactive` lifts on hover; `padding` none|sm|md|lg; `as` swaps the element (e.g. `as="a"`).
